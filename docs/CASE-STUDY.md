# NYQVRA — продуктовый кейс

[English](CASE-STUDY.en.md) · **Русский**

## Задача

Создавать результат локально и объяснять стойкость без перегруженного технического экрана. Дать быстрый доступ через сайт и автономную копию без интернета.

## Анализ формата

Изучена публичная документация [Homelab Vault](https://github.com/jakubgt/homelab-vault-gen), [Offline Password Generator](https://github.com/spidersalt/offline-password-generator) и [KeePassXC](https://github.com/keepassxreboot/keepassxc). Первые два показывают браузерную/автономную модель; KeePassXC — более широкую категорию настольных менеджеров. Это не аудит чужого кода.

Выбраны сайт и готовая офлайн-папка с общим ядром. Нативный установщик не добавлялся только ради упаковки.

## Визуальная система и UX

Прозрачный рыцарь — образ защиты, стеклянная панель — рабочая поверхность. Лиловый акцент объединяет действия, знак и детали. Рыцарь статичен; движение оставлено у знака с учётом reduced motion.

- Результат на главном экране, без регистрации.
- Смена настроек не уничтожает уже созданный результат.
- Копирование и скрытие рядом: иконки с доступными названиями.
- Оценка и объяснение объединены в одну кликабельную строку.
- Формулы и огромные сроки убраны из UI в документацию.
- Длинный результат увеличивает панель, а не обрезается.
- На узком экране блоки перестраиваются.
- Размытое продолжение фона сохраняет отдалённый масштаб рыцаря.

## Реализация и границы

Web Crypto, выбор без смещения, энтропия с учётом обязательных классов, встроенный список EFF. Нет отправки и постоянного хранения результатов. Оценка касается перебора, не заменяет MFA, менеджер паролей или безопасность устройства.

Результат сопровождается тестами, браузерной проверкой, инструкцией автономного запуска, контрольными суммами и исходным кодом. Это не независимый security audit.

Нет исследований с участниками, данных о конверсии, подтверждённых продуктовых метрик или сертификации. Следующий этап — пользовательские проверки и независимое ревью безопасности. Нельзя приписывать этому кейсу несуществующий коммерческий эффект.
