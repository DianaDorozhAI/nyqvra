# Как рассчитывается оценка

[English](SECURITY-MODEL.en.md) · **Русский**

Оцениваются только результаты генерации NYQVRA. Для придуманного человеком пароля эта модель неприменима: одинаковая длина не означает одинаковую предсказуемость.

## Случайный выбор

Все разрешённые символы имеют одинаковый шанс выбора. `crypto.getRandomValues()` предоставляет случайные значения; rejection sampling отбрасывает значения вне полного кратного диапазона, чтобы остаток деления не создавал смещения.

Для символов используется 8-битное пространство, для 7 776 слов — 16-битное. Нет fallback на `Math.random()`.

Без обязательных классов: `H = L × log2(N)` бит, где L — длина, N — размер набора. Если каждый выбранный непересекающийся класс обязателен, число допустимых строк вычисляется включением–исключением. Неподходящий кандидат целиком отбрасывается; принудительной вставки нет.

Для K слов: `H = K × log2(7776)`. Выбор независимый, повторения допустимы. Фиксированный пробел не добавляет энтропии; внутренние дефисы сохранены.

## Перебор

Пусть `M = 2^H`, скорость r попыток/с, период t секунд. Для равномерного результата при переборе без повторов:

- Среднее число попыток: `(M + 1) / 2`.
- Среднее время: `(M + 1) / (2 × r)`.
- Вероятность нахождения за период: `min(floor(r × t) / M, 1)`.

Вычисления используют логарифмы для устойчивости больших чисел. UI не показывает астрономические сроки как прогноз взлома.

| Сценарий | Условная скорость |
| --- | ---: |
| Через форму входа | 10 попыток/с |
| Медленная проверка после утечки | 10 000 попыток/с |
| Быстрая проверка после утечки | 10 000 000 000 попыток/с |

Это иллюстративные значения, не измерения конкретного сервиса, алгоритма хранения или оборудования. Блокировки и MFA не моделируются.

Каждая строка сравнивает вероятность за **86 400 секунд**:

- Высокая: `p < 10^-12`.
- Средняя: `p < 10^-6`, если не выполнен первый порог.
- Низкая: остальные значения.

Главный индикатор использует самый быстрый сценарий. Поэтому 8 цифр — слабый результат, а 24 символа из полного набора — сильный в этой модели. Пороги — редакционный выбор интерфейса, не отраслевой стандарт или сертификация.

Не учитываются фишинг, вредоносное ПО, повторное использование, кража самого пароля, расширения, ошибки сервиса и утечки памяти/буфера. NYQVRA не проверяет аккаунты и не атакует сервисы. Независимый аудит не проводился.
