NYQVRA 0.2 — методика / calculation method

Область применения: только результаты генератора NYQVRA. Не оценка введённого человеком пароля.
Scope: NYQVRA-generated outputs only, not human-chosen passwords.

Источник: Web Crypto crypto.getRandomValues. Нет Math.random fallback.
Выбор индекса: rejection sampling. Для символов 8-bit, для EFF слов 16-bit.
При обязательных наборах отклоняется весь неподходящий кандидат; вставки символов нет.

Для независимых равновероятных выборов H=L*log2(N).
Для обязательных непересекающихся классов H=log2(number of valid strings),
число строк вычисляется включением-исключением.
EFF Large Wordlist: 7776 разных английских слов; K независимых выборов.
H=K*log2(7776). Фиксированный пробел не добавляет энтропии.
Слова с внутренним дефисом сохранены. Пробелы делают разбиение однозначным.

Условный равномерный перебор без повторов. N=2^H.
Среднее число попыток (N+1)/2; среднее время (N+1)/(2*r).
Вероятность за t секунд: min(floor(r*t)/N,1), для целого бюджета попыток.
Иллюстративные сценарии: r=10, 10000, 10000000000 попыток в секунду.
Это не измеренные скорости конкретного устройства, алгоритма хеширования или сервиса.
Без блокировок, MFA, знания пароля, неслучайного выбора и утечек открытого текста.

Качественные подписи сравнивают вероятность за 86400 секунд:
«Высокая»: p<1e-12; «Средняя»: p<1e-6; иначе «Низкая».
Главный экран использует самый быстрый из трёх сценариев.
Это редакционные пороги интерфейса, не отраслевой стандарт и не сертификация.
Большие числа не являются прогнозом реального будущего взлома.

Не учитываются фишинг, вредоносное ПО, повторное использование, кража памяти,
расширения браузера, доступ других программ к буферу, ошибки или взлом самого сервиса.
Приложение не знает способ хранения пароля конкретным сайтом.
Генерация не проверяет аккаунты, не отправляет запросы в сервисы и не атакует их.
Модель не является независимым аудитом или гарантией безопасности.

Privacy: no accounts, telemetry, API requests, password history or persistent password storage.
Passwords remain in process memory until replaced or closed; RAM erasure is not guaranteed.
Clipboard history and synchronization are controlled by the OS. No automatic clearing in 0.2.
