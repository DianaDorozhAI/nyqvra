# NYQVRA

[English](README.md) · **Русский**

Генератор случайных паролей и парольных фраз с понятной оценкой стойкости к подбору.

[Открыть сайт](https://dianadorozhai.github.io/nyqvra/) · [Скачать офлайн](https://github.com/DianaDorozhAI/nyqvra/releases/latest) · [Методика](docs/SECURITY-MODEL.md) · [Безопасность](SECURITY.md)

## Возможности

- Пароли длиной 8–128 символов: буквы, цифры и специальные символы.
- Парольные фразы из 4–10 английских слов EFF Large Wordlist.
- Настройка «хотя бы один символ из каждого выбранного набора».
- Оценка «Надёжный», «Средняя стойкость» или «Слабый» и объяснение для разных условий подбора.
- Копирование и скрытие результата; интерфейс на русском и английском.
- Работа без аккаунта, аналитики и истории результатов.

Настройки применяются при следующей генерации: текущий результат не исчезнет, пока вы меняете длину или наборы.

## Два способа запуска

### В браузере

[Открыть NYQVRA](https://dianadorozhai.github.io/nyqvra/). Сайт загружает приложение и ресурсы с GitHub Pages. Пароль создаётся в вашем браузере, а не на сервере.

Хостинг обрабатывает обычные запросы загрузки страницы; «пароли не отправляются» не означает, что посещение сайта не видно хостингу. Для автономного запуска скачайте архив.

### На компьютере, без интернета

1. Откройте [последний релиз](https://github.com/DianaDorozhAI/nyqvra/releases/latest).
2. В Assets скачайте **`NYQVRA-0.2.0-offline.zip`** — это готовое приложение, не `Source code.zip`.
3. Распакуйте **весь** архив и откройте **`index.html`** в современном браузере.

Установка, Node.js и интернет не нужны. Это автономное веб-приложение, **не Windows `.exe` и не устанавливаемая PWA**. На телефоне проще пользоваться сайтом; автономное открытие файлов зависит от системы и браузера.

Если браузер запрещает доступ к буферу из локального файла, выделите результат и скопируйте вручную. Не открывайте HTML прямо внутри ZIP.

Рядом с архивом опубликован `SHA256SUMS.txt`. В PowerShell:

```powershell
Get-FileHash .\NYQVRA-0.2.0-offline.zip -Algorithm SHA256
```

Сравните значение с контрольной суммой официального релиза. Совпадение подтверждает целостность загрузки, но не доказывает отсутствие уязвимостей.

## Что означает оценка

Она относится **только к результату этого генератора** и оценивает перебор вариантов. Длина, набор символов и способ генерации определяют число возможных результатов. Три сценария показывают, как меняется оценка при разных скоростях проверки.

Общий индикатор использует наиболее быстрый сценарий за условные сутки. Пороги интерфейса выбраны проектом, а не взяты из сертификационного стандарта. Короткая строка только из цифр может быть слабой.

Формулы, скорости и пороги вынесены в [методику](docs/SECURITY-MODEL.md), а не загружают основной экран. Это не проверка конкретного сайта, не измерение оборудования и не обещание времени взлома.

## Безопасность и приватность

- Источник случайности — `crypto.getRandomValues()`. Rejection sampling исключает смещение при выборе индекса. Небезопасного запасного генератора нет.
- При обязательных наборах отклоняется весь неподходящий кандидат. Энтропия учитывает ограниченное пространство результатов.
- Список из 7 776 слов, шрифт и иконки включены в сборку. Нет CDN, внешних API, телеметрии, localStorage или IndexedDB для паролей.
- CSP запрещает сетевые подключения из приложения: `connect-src 'none'`.
- Пароль остаётся в памяти вкладки. Гарантированного стирания памяти нет. После копирования он также находится в системном буфере, который могут читать другие программы. Историей и синхронизацией буфера управляет ОС.

**Границы:** NYQVRA не защищает от фишинга, вредоносного ПО, расширений браузера, повторного использования пароля или взлома самого сервиса. Нет хранилища, восстановления, проверки утечек и анализа введённых пользователем паролей. Парольные фразы не являются seed-фразами криптокошелька.

Независимый аудит безопасности пока не проводился. Порядок сообщения об уязвимостях — в [SECURITY.md](SECURITY.md). Сохраняйте результаты в менеджере паролей.

## Разработка и проверки

Требуется Node.js 22 или 24. Зависимостей npm и стороннего серверного фреймворка нет.

```sh
git clone https://github.com/DianaDorozhAI/nyqvra.git
cd nyqvra
npm run build
npm test
npm run dev
```

Откройте `http://127.0.0.1:4173/`. Готовая веб-сборка находится в `dist/`.

```sh
npm run preview
npm run package
```

Последняя команда создаёт офлайн-ZIP и контрольную сумму в `outputs/`. В архив попадают только файлы из [явного списка ресурсов](scripts/runtime-files.mjs), не рабочие материалы. [Инструкция релиза](docs/RELEASING.md).

Тесты проверяют выбор случайного индекса, обязательные наборы, энтропию, сценарии, валидацию, список слов, сборку, ZIP и ограничения локального сервера. CI запускает их на Windows и Linux с Node.js 22/24. Это не доказательство отсутствия всех ошибок и не сертификация.

| Файл | Назначение |
| --- | --- |
| `src/password.js` | Генерация и энтропия |
| `src/threat-model.js` | Модель перебора |
| `src/settings.js` | Валидация параметров |
| `src/main.js` | Состояние, действия, RU/EN |
| `src/engineering.css` | Адаптивный интерфейс |
| `src/engineering-effects.js` | Анимация знака, без доступа к паролю |
| `test/` | Автоматические проверки |

## English

NYQVRA is a browser-local password and passphrase generator with an explainable guessing-resistance estimate. [Try it online](https://dianadorozhai.github.io/nyqvra/) or [download the offline ZIP](https://github.com/DianaDorozhAI/nyqvra/releases/latest), extract everything and open `index.html`. No installer or internet is needed for the downloaded version.

Passwords use Web Crypto and unbiased rejection sampling. The app does not send or persist passwords. Clipboard and process memory have limitations; the rating is not an account-security guarantee. No independent security audit has been performed. The project's own code has no open-source license selected yet; third-party notices remain applicable.
